# Учёт студентов и успеваемости

Исправленная версия чужого проекта из ветки `ошибки-человечества` репозитория
[`MetalSonic882/RPM_PR_1`](https://github.com/MetalSonic882/RPM_PR_1).
Репозиторий подготовлен для сдачи как чистая копия без паролей и служебных файлов IntelliJ IDEA.
Анализ исходной версии, перечень изменений, оценка и скриншоты проверки находятся в файлах
`ANALYSIS.md` и `Отчёт_анализ_и_рефакторинг_RPM_PR_1.docx`.
Презентация для защиты находится в файле `Презентация_защита_RPM_PR_1.pptx`.

Ветка `main` содержит исправленную версию, а ветка `errors-original` — учебный вариант «до».
Перед публикацией из исходной ветки удалены реальные учётные данные базы данных.

## Настройка базы данных

Приложение использует MySQL. Параметры подключения передаются через переменные окружения:

- `STUDENT_DB_URL` — адрес базы данных;
- `STUDENT_DB_USER` — пользователь;
- `STUDENT_DB_PASSWORD` — пароль.

Если URL и пользователь не заданы, применяются `jdbc:mysql://localhost:3306/student_db...` и `root`. Пароль по умолчанию пустой. Секреты в репозитории не хранятся.

Перед первым запуском следует выполнить миграции Flyway, затем запустить JavaFX-приложение:

```powershell
.\mvnw.cmd flyway:migrate
.\mvnw.cmd javafx:run
```

## Основные исправления

- исправлен обработчик кнопки добавления студента;
- исправлен главный класс Maven;
- удалены пароли из исходного кода и `pom.xml`;
- запросы выполняются в фоновом JavaFX `Task`;
- устранён повторный запрос списка студентов;
- добавлена пагинация по 25 записей;
- добавлены индексы и ограничение оценки от 1 до 5;
- модели сделаны неизменяемыми, связанные данные выделены в объекты-значения;
- ошибки БД передаются в интерфейс, а не только печатаются в консоль.
