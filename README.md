# RPM PR 1 — версия до исправлений

Это учебная исходная версия из ветки `ошибки-человечества`, используемая для сравнения с исправленным проектом.

Ветка намеренно сохраняет найденные ошибки: неверный обработчик FXML, ошибочную точку входа Maven, повторные запросы, работу JDBC в JavaFX-потоке, отсутствие пагинации и другие проблемы, описанные в отчёте.

Реальные учётные данные MySQL перед публикацией заменены на `CHANGE_ME`. Исправленная версия находится в ветке `main`.
